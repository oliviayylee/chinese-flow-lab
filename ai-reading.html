학습자 인지 프로파일과 XAI 분석 결과를 바탕으로 개인별 Prompt를 자동 구성하고, 맞춤형 읽기 지문·설명·문항·피드백으로 연결합니다.

학습자 프로파일을 불러오고 있습니다.

프롬프트 처리 구조

학습자의 읽기 수행 결과에서 도출된 인지 프로파일과 XAI 원인 설명을 생성형 AI의 입력 조건으로 구조화합니다.

1

인지 프로파일

학습 수준 · 취약영역 · 영역별 처리 특성

2

XAI 원인 분석

처리 부담이 높은 세부 언어 요인 설명

3

Prompt 자동 생성

수준 · 취약영역 · 지원 목표 구조화

4

생성형 AI

구조화된 Prompt를 API로 전달

5

맞춤형 읽기 지원

지문 · 설명 · 문항 · 개인맞춤형 피드백

Input

참여자 ID
-

-

Output

생성형 AI는 개인별 Prompt에 따라 다음과 같은 읽기 지원을 생성하도록 설계합니다.

맞춤형 읽기 지문 학습 수준과 취약영역을 반영한 짧은 중국어 읽기 자료
문법 설명 학습자에게 처리 부담이 높게 나타난 통사 구조 중심의 설명
